# Brand assets

The logo, favicon and locally hosted fonts mirror the assets used by
[`heisel.one`](https://www.heisel.one/) on 2026-09-14. Keeping copies in the
repository avoids runtime dependencies on the main website.

- `logo/oliver-heisel-wordmark.png`: source mask for the current white and neon yellow wordmark
- `favicon.svg`: current website favicon
- `fonts/`: Montserrat (headings) and Open Sans (body copy)
